# my-word-game

1人でも2人でも遊べる、ブラウザ向けのひらがな言葉当てゲームです。

## Ver.3の特徴

- 1人用: 1・3・5ラウンドでスコアと自己ベストに挑戦
- 2人用: 1台の端末を交互に使う得点対戦
- かんたん・ふつう・むずかしいの3段階
- 8カテゴリ、200語を収録
- セッション中と直近出題の重複を抑制
- カタカナ入力をひらがなへ自動変換
- 単語解答、ヒント、プレイヤー別得点、延長戦
- 音声設定、自己ベスト、直近出題を端末内に保存
- 320px幅、キーボード、読み上げ、動きを減らす設定に対応

## 遊び方

### 1人用

隠れた言葉を一文字ずつ当て、規定ラウンドの合計スコアを競います。文字正解、単語正解、残りライフ、早解きで得点し、ヒントを使うと減点されます。

### 2人用

同じ言葉を見ながら、1回ずつ交互に回答します。正解文字と単語正解でプレイヤー別に得点し、全ラウンドの合計点で勝者を決めます。ラウンドごとに先攻が交代します。

### 共通ルール

- 一文字の不正解: ライフ1減少
- 単語解答の不正解: ライフ2減少
- 使用済み文字・使用済み解答: ペナルティなし
- ヒント: 隠れている同じ文字をすべて開き、そのラウンドで得た得点から最大150点減点

## 音声

BGMと効果音は`audio-engine.js`がWeb Audio APIでブラウザ内生成します。外部音源やローカルMP3ファイルは使用しません。

音声はいつでもオン・オフでき、オフにした場合は再生予約済みの音も停止します。Web Audio APIへ対応していない場合もゲーム本体は無音で続行します。

## 構成

- `words.js`: 200語の出題データと選出
- `game-state.js`: 得点、ライフ、ターン、ラウンド、勝敗
- `storage.js`: 設定、自己ベスト、直近出題の安全な保存
- `game-ui.js`: 画面表示と操作
- `audio-engine.js`: BGMと効果音
- `styles.css`: レスポンシブUI
