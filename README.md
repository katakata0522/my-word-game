# my-word-game

1人でも2人でも遊べる、ブラウザ向けのひらがな言葉当てゲームです。

## Ver.3の特徴

- 1人用: 1・3・5ラウンドでスコアと自己ベストに挑戦
- 2人用: 1台の端末を交互に使う得点対戦
- 今日の一問: 日付で固定された同じ問題へ毎日挑戦
- かんたん・ふつう・むずかしいの3段階
- 8カテゴリ、200語を収録
- 意味の手がかりを読んでから、文字または単語を推理
- カテゴリを分散し、セッション中と直近出題の重複を抑制
- カタカナ入力をひらがなへ自動変換
- 一部の一般的な別名・略称も正解として受付
- 単語解答、ヒント、プレイヤー別得点、延長戦
- 音声設定、ラウンド数別自己ベスト、通算成績、日替わり記録を端末内に保存
- 320px幅、キーボード、読み上げ、動きを減らす設定に対応
- アプリを閉じていた時間を早解き判定から除外

## 遊び方

### 1人用

意味の手がかりを読み、隠れた言葉を一文字ずつ当てます。規定ラウンドの合計スコアを競い、単語を早い段階で当てるほど高得点になります。自己ベストは難易度とラウンド数の組み合わせごとに保存されます。

### 2人用

同じ言葉を見ながら、1回ずつ交互に回答します。正解文字と単語正解でプレイヤー別に得点し、全ラウンドの合計点で勝者を決めます。ラウンドごとに先攻が交代します。単語解答を外した場合は共有ライフを減らさず、回答者だけが100点減点されます。

### 今日の一問

毎日、全員に同じ「ふつう」難易度の問題が出題されます。その日の最初の結果だけを正式記録とし、以降は練習として再挑戦できます。サーバーやアカウントは使用せず、日付から同じ問題を決定します。

### 共通ルール

- 一文字の不正解: ライフ1減少
- 1人用の単語解答ミス: ライフ2減少
- 2人用の単語解答ミス: 回答者が100点減点
- 使用済み文字・使用済み解答: ペナルティなし
- 文字ヒント: 隠れている同じ文字をすべて開き、150点減点
- 単語正解: 残っている伏字が多いほど高得点
- 早解き: 単語の長さに応じた基準時間から1秒単位で計算

## 音声

BGMと効果音は`audio-engine.js`がWeb Audio APIでブラウザ内生成します。外部音源やローカルMP3ファイルは使用しません。

音声はいつでもオン・オフでき、オフにした場合は再生予約済みの音も停止します。Web Audio APIへ対応していない場合もゲーム本体は無音で続行します。

## 構成

- `words.js`: 200語の出題データと選出
- `game-state.js`: 得点、ライフ、ターン、ラウンド、勝敗
- `storage.js`: 設定、自己ベスト、直近出題の安全な保存
- `game-ui.js`: 画面表示と操作
- `audio-engine.js`: BGMと効果音
- `styles.css`: レスポンシブUI
